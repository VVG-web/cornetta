No telemetry. No tracking.

This version of Cornetta sends no usage data, uses no analytics and has no feedback server. Recordings and transcripts stay on your computer.

Updated 7 November 2026.

Recordings and transcripts

They stay on your computer, in the Music › Cornetta folder. Transcription uses the Mac's speech recognition and runs on the Mac. Cornetta does not send audio, text, file names, device names or contacts to any server.

Usage data

There is no telemetry, installation identifier, analytics or automatic crash report. The app opens no background connections.

GitHub update check

The only possible network connection is the one you start from the menu with Check for updates on GitHub…. At that moment the app asks GitHub for the latest release of VVG-web/cornetta-en. The request contains the app version and a normal User-Agent; it contains no audio, text or file names. GitHub sees your IP address and applies its own privacy policy. Cornetta does not download or install updates automatically.

Feedback

The Feedback button opens a new public GitHub issue in your browser. Nothing is submitted automatically from the app: you write the text and decide whether to publish it. The issue is public and handled by GitHub.

The website

This is a static site. It uses no cookies, Plausible, Telegram or other analytics, and it does not count visits. The only network requests are the ones needed to load pages and images from the server hosting the site.

Other services

macOS may download Apple speech models once when you use transcription. That is a system operation, not Cornetta, and it does not send the call content. GitHub is the only external service used by the app, and only for actions you choose.

Who maintains this version

This is an open-source fork maintained by VVG-web, based on the original project by Federico Nejrotti. For problems or questions, open a GitHub issue.
