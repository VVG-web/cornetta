Scarica

Nessuna telemetria. Nessun tracciamento.

Questa versione di Cornetta non manda dati di funzionamento, non usa analytics e non ha un server di feedback. Registrazioni e trascrizioni restano sul computer.

Aggiornata il 7 novembre 2026.

Registrazioni e trascrizioni

Restano sul tuo computer, nella cartella Musica › Cornetta. La trascrizione usa il riconoscimento vocale del Mac e gira sul Mac. Cornetta non invia audio, testo, nomi di file, nomi di dispositivi o contatti a nessun server.

Dati di funzionamento

Non ci sono telemetria, identificativi di installazione, analytics o rapporti automatici di errore. L'app non apre connessioni in background.

Controllo aggiornamenti su GitHub

L'unica connessione di rete possibile è quella che avvii tu dal menu con Controlla gli aggiornamenti su GitHub…. In quel momento l'app chiede a GitHub l'ultima release del repository VVG-web/cornetta-en. La richiesta contiene la versione dell'app e un normale User-Agent, non contiene audio, testi o nomi di file. GitHub vede l'indirizzo IP e applica la propria informativa. Cornetta non scarica e non installa aggiornamenti da sola.

Feedback

Il pulsante Feedback apre una nuova segnalazione pubblica su GitHub nel browser. Non c'è nessun invio automatico dall'app: scrivi tu il testo e decidi se pubblicarlo. La segnalazione è pubblica e gestita da GitHub.

Il sito

Questo sito è statico. Non usa cookie, Plausible, Telegram o altri servizi di analisi, e non conta le visite. Le uniche richieste di rete sono quelle necessarie a caricare le pagine e le immagini dal server che ospita il sito.

Altri servizi

MacOS può scaricare una volta i modelli vocali di Apple quando usi la trascrizione. È un'operazione del sistema, non di Cornetta, e non invia il contenuto della chiamata. GitHub è l'unico servizio esterno usato dall'app, e solo per le azioni che scegli tu.

Chi mantiene questa versione

Questo è un fork open source mantenuto da VVG-web, basato sul progetto originale di Federico Nejrotti. Per problemi o domande apri una segnalazione su GitHub.
